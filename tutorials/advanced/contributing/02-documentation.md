# 文档贡献

> 📚 难度：初级 | ⏱️ 预计时间：1-2 天 | 🎯 目标：学会为项目贡献文档

本教程讲解如何为 OpenCode 贡献文档。

---

## 1. 文档类型

### 1.1 文档分类

```
docs/
├── tutorials/          # 教程
├── api/               # API 文档
├── guides/            # 指南
├── examples/          # 示例
└── reference/         # 参考
```

---

## 2. 文档规范

### 2.1 Markdown 规范

```markdown
# 标题

## 二级标题

正文内容，简洁明了。

### 代码示例

\`\`\`typescript
const example = "代码要有类型"
\`\`\`

### 列表

- 要点 1
- 要点 2
  - 子要点

### 表格

| 列1 | 列2 |
| --- | --- |
| A   | B   |
```

### 2.2 写作风格

- 使用简洁的语言
- 多用示例说明
- 保持结构清晰
- 及时更新

---

## 3. 翻译工作

### 3.1 翻译流程

```bash
# 1. 找到需要翻译的文件
docs/en/getting-started.md

# 2. 创建翻译文件
docs/zh/getting-started.md

# 3. 翻译并提交 PR
```

---

## 4. 本章总结

### 贡献方式

- 修正错误
- 完善教程
- 添加示例
- 翻译文档

### 质量要求

- 准确无误
- 通俗易懂
- 结构清晰
- 及时更新

---

**好文档让项目更易用！**
