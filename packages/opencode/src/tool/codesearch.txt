- 使用 Exa Code API 搜索并获取与编程任务相关的上下文
- 为库、SDK、API 提供高质量、最新的上下文
- 任何与编程相关的问题或任务均可使用本工具
- 返回代码示例、文档与 API 参考
- 针对特定编程模式与解决方案的查找做了优化

用法说明：
  - 可调 token 数量（1000–50000），便于聚焦或全面检索
  - 默认 5000 token 对多数查询提供均衡上下文
  - 具体问题用较小值，全面文档用较大值
  - 支持框架、库、API 及编程概念类查询
  - 示例：'React useState 示例'、'Python pandas 筛选'、'Express.js 中间件'
