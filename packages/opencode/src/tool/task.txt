启动新的智能体以自主处理复杂、多步骤任务。

可用智能体类型及其可用工具：
{agents}

使用 Task 工具时必须指定 subagent_type 参数以选择要使用的智能体类型。

何时使用 Task 工具：
- 当被要求执行自定义斜杠命令时。使用 Task 工具并将斜杠命令调用作为完整 prompt。斜杠命令可带参数。例如：Task(description="检查文件", prompt="/check-file path/to/file.py")

何时不要使用 Task 工具：
- 若要读取特定文件路径，请使用 Read 或 Glob 工具而非 Task，以更快定位
- 若在搜索特定类定义如 "class Foo"，请使用 Glob 工具而非 Task，以更快定位
- 若在特定文件或 2–3 个文件中搜索代码，请使用 Read 工具而非 Task，以更快定位
- 与上述智能体描述无关的其他任务

用法说明：
1. 尽可能并发启动多个智能体以提高效率；在同一轮消息中发起多次 Task 调用即可
2. 智能体完成后会向你返回一条消息。该结果对用户不可见。若要展示给用户，请再发一条文字消息，简要总结结果。输出中包含 task_id，之后可复用以继续同一子会话。
3. 每次调用默认为新上下文，除非提供 task_id 以恢复同一子会话（将延续其历史与工具输出）。新建时，prompt 中应包含足够详细的任务描述供智能体自主执行，并明确说明你希望智能体在最终唯一一条回复中返回哪些信息。
4. 一般可信任智能体的输出
5. 明确告知智能体你期望其写代码还是仅做调研（搜索、读文件、网页获取等），因其无法获知用户意图。若可能，说明如何验证结果（如相关测试命令）。
6. 若智能体描述中提到应主动使用，则尽量在用户未明确要求时也使用，由你判断。

示例（注意：以下智能体仅为示例，请使用上方列出的实际智能体）：

</example_agent_description>

  if (n <= 1) return false

  }
  return true
}
</code>

</commentary>
